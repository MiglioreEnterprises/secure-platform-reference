# Secure Kubernetes Platform Reference Architecture 
This repository demonstrates the automated deployment and operation of a production-style Kubernetes platform on virtualized infrastructure. 

Core technologies: 
- Proxmox 
- Terraform 
- Kubernetes 
- Helm 
- Argo CD 
- Prometheus 
- Grafana 
- GitHub Actions 

The project focuses on: 
- reproducible infrastructure 
- GitOps 
- platform observability 
- Kubernetes security 
- resiliency 
- automated operations
